# Figure source data and scripts

This collection provides processed source data and standalone scripts for
reproducing the manuscript figures without rerunning the catchment simulations.
Each figure has its own directory and README. Figures 1-5 and Extended Data Figures 1 and 2 are currently included.

These files complement the model configurations and forcing-preparation workflow.

If you use these data or scripts, please cite our manuscript and the original
datasets referenced therein.
