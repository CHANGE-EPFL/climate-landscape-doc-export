# Climate, landscape and DOC export

Model configurations, source data and analysis scripts for assessing how climate
change and landscape features shape future dissolved organic carbon export.

## Contents

- [T&C model configurations and inputs](T&C/README.md): meteorological data
  preparation and contemporary and future simulations for 12 catchments.
- [Figure source data and scripts](figure%20source%20data%20and%20script/README.md):
  standalone workflows for Figures 1-5 and Extended Data Figures 1-2.

Follow the README in each folder for dependencies and reproduction steps.
Large raw simulation outputs and local Python environments are not included.

## Citation

If you use these data or code, please cite our manuscript and the associated
datasets referenced therein.
