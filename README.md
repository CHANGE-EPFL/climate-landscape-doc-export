# Data and code supporting the manuscript

This repository provides the model configurations, inputs, figure source data
and analysis scripts supporting the manuscript:

**Landscape form modulates climate-driven changes in dissolved organic carbon export**

Taiqi Lian, Ruiqi Gu, Ziyan Zhang, Athanasios Paschalis and Sara Bonetti.

The study examines how climate change and landscape features shape future
dissolved organic carbon (DOC) export, using distributed ecohydrological and
biogeochemical simulations across 12 catchments in the contiguous United States
and Switzerland, together with continental-scale vulnerability mapping.

## Contents

- [T&C model configurations and inputs](T&C/README.md): meteorological data
  preparation and contemporary and future simulations for the 12 catchments.
- [Figure source data and scripts](figure%20source%20data%20and%20script/README.md):
  data and standalone analysis and plotting scripts for Figures 1-5 and
  Extended Data Figures 1-2.

Follow the README in each folder for dependencies and reproduction steps.
Large raw simulation outputs and local Python environments are not included.
